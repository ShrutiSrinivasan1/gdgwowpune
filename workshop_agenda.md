# Workshop Agenda: Introduction to GitHub

## Overview

This hands-on workshop provides participants with practical experience using GitHub for version control and collaboration. Participants will learn essential GitHub workflows, from basic concepts to collaborative development practices.

## Schedule

| Time | Activity |
|------|----------|
| 10:00 - 10:30 | **Registration and Welcome** |
| 10:30 - 11:15 | **Introduction to Version Control and GitHub** <br> - Why version control matters <br> - Key GitHub concepts <br> - Creating a GitHub account |
| 11:15 - 12:00 | **Hands-on: Basic GitHub Operations** <br> - Creating repositories <br> - Making commits <br> - Writing effective README files |
| 12:00 - 12:45 | **Lunch Break** |
| 12:45 - 14:00 | **Collaborative Workflows** <br> - Branching strategies <br> - Creating pull requests <br> - Code reviews <br> - Resolving merge conflicts |
| 14:00 - 15:00 | **GitHub Features for Project Management** <br> - Issues and project boards <br> - GitHub Actions basics <br> - GitHub Pages |
| 15:00 - 15:30 | **Tea Break** |
| 15:30 - 16:30 | **Team Exercise: Collaborative Project** <br> - Working in teams to practice pull requests and code reviews |
| 16:30 - 17:00 | **Q&A and Closing Remarks** |

## Prerequisites

- Laptop with internet connection
- GitHub account (can be created during the workshop)
- Git installed on your machine (instructions will be provided)
- Basic understanding of command line interface (helpful but not required)

## What You'll Learn

- Essential Git and GitHub vocabulary and concepts
- How to create and manage repositories
- Best practices for collaboration
- How to contribute to open source projects
- Troubleshooting common GitHub issues

## Workshop Materials

All workshop materials will be available in this repository, including:
- Presentation slides
- Exercise instructions
- Reference guides
- Additional resources for continued learning

We look forward to coding with you!

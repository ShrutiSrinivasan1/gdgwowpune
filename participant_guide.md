# Participant Guide: GitHub Workshop

Welcome to the GDG WOW Pune GitHub workshop! This guide will help you prepare for the workshop and make the most of your learning experience.

## Before the Workshop

### 1. Create a GitHub Account

If you don't already have a GitHub account, please create one before the workshop:
- Go to [github.com](https://github.com)
- Click "Sign up" and follow the instructions
- Verify your email address

### 2. Install Git

Install Git on your computer:
- **Windows**: Download and install from [git-scm.com](https://git-scm.com/download/win)
- **macOS**: 
  - Option 1: Install with Homebrew: `brew install git`
  - Option 2: Download from [git-scm.com](https://git-scm.com/download/mac)
- **Linux**: Use your package manager, e.g., `sudo apt-get install git` (Ubuntu/Debian)

### 3. Configure Git

Open a terminal or command prompt and set your Git identity:
```
git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
```

### 4. Basic Terminal/Command Line Knowledge

Familiarize yourself with basic terminal commands:
- `cd` - Change directory
- `ls` (macOS/Linux) or `dir` (Windows) - List files
- `mkdir` - Create a directory

## What to Bring
